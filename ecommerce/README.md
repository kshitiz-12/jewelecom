# B.L. Hissaria — Ecommerce

Jewellery boutique shop on the same quiet-luxury theme as the brand site.

## Run

```bash
cd ecommerce
npm install
npm run dev
```

Opens at [http://localhost:5174](http://localhost:5174).

## Features

- Product catalog (12 pieces with generated photography)
- Category filters, metal filters, price range, in-stock toggle
- Search + sort (featured, newest, price, name)
- Product detail pages
- Cart with quantity controls (persisted in `localStorage`)

## Stack

React 19 · Vite · Tailwind CSS v4 · React Router
